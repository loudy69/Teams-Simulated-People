Teams Demo Attendees - portable install
=======================================
Requires: Windows 10/11, Microsoft Edge, internet access (first install only).

1. Unzip this folder anywhere.
2. Double-click Install.cmd (installs Node.js LTS via winget if missing, then npm packages,
   and creates a desktop shortcut).
3. Double-click Start.cmd (or the desktop shortcut). The UI opens at http://localhost:3000.
4. Enter Meeting ID + Passcode, choose 1-12 people, click Join.

Notes
- Clips are pre-built (clips\*.mjpeg, watermarked "Teams Demo - these are not real people"); no ffmpeg needed.
- Meeting must allow anonymous join; admit guests from the lobby. Attendees have no audio.
- Use BROWSER_CHANNEL=chrome to use Chrome instead of Edge.

VOICED CONVERSATIONS
- Requires Python (installed by Install.cmd) for neural voices, plus an LLM key set before Start.cmd:
    setx OPENAI_API_KEY sk-...   (or LLM_API_KEY / LLM_ENDPOINT / LLM_MODEL for any OpenAI-compatible API)
- In the UI pick an industry, edit the topic brief, wait until all attendees are admitted, then click Start conversation.

Version 2.0: voiced conversations. Optional: install Foundry Local for token-free dialogue; otherwise set OPENAI_API_KEY.
